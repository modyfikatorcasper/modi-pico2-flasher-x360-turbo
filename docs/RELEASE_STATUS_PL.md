# Stan wydania — 0.9.1 Beta (publiczna)

[Gotowa paczka ZIP](https://github.com/modyfikatorcasper/modi-pico2-flasher-x360-turbo/releases/download/v0.9.1-beta/MODI-Pico2-Flasher-X360-TURBO-v0.9.1-beta.zip) · [Wydanie i osobne pliki](https://github.com/modyfikatorcasper/modi-pico2-flasher-x360-turbo/releases/tag/v0.9.1-beta)

Instalator offline i jedna paczka ZIP są publiczne. Test instalacji w świeżym folderze przeszedł: weryfikacja oryginału, zachowanie jego plików, ponowny start oraz odrzucanie niezgodnych i niepełnych instalacji. 753 metody odpowiadają sprawdzonej integracji; 18 testów integracji bez sprzętu przeszło. Firmware pozostaje niezmieniony.

Użytkownik potwierdził 2026-10-04: „TEST SA WYKONA WSZYSTKO DZIALA”, w odpowiedzi na prośbę o końcowy test sprzętowy. To potwierdzenie użytkownika; agent nie wykonał nowego pomiaru czasów ani nie otrzymał nowych hashy kontroli po zapisie.

Publikacja i weryfikacja hashy przeszły. Oficjalny J-Runner r7 pobrany podczas kontroli pasuje do SHA256 wymaganego przez instalator. [Strona projektu](https://modyfikatorcasper.github.io/modi-pico2-flasher-x360-turbo/) została wdrożona poprawnie.

Prawdziwy screenshot pozostaje do dodania po timeoutach przechwytywania okna. Przegląd odziedziczonej rozbieżności nagłówków GPLv2 i pliku LICENSE GPLv3 firmware pozostaje otwarty; oryginalne teksty oraz komplet źródeł są zachowane.
