Why we built it

When Xbox 360 RGH servicing began, NAND operations could take tens of minutes with early interfaces such as LPT. USB programmers changed that. Today a low-cost RP2350 board gives us another chance to rethink the workflow.
Giving back to the community

I learned from this community when I was beginning as a repair technician. After years of hardware service and diagnostics, this project is my way of giving something back: useful tools, documentation and knowledge for repair.

Repair-first project. Independent community tool. Not affiliated with Microsoft or Xbox. Users are responsible for how they use the tool and for compliance with applicable law.

Quick start

Download the matching MODI Pico 2 TURBO UF2 from the GitHub Release.
Enter BOOTSEL mode and copy the UF2 to the Pico 2 / supported RP2350 board.
Wire the flasher to the correct service points for the target motherboard and flash type.
Run MODI Setup, point it at compatible J-Runner with Extras 3.4.0.7, then use the locally created JRunner.MODI.exe.
READ → BACKUP → COMPARE / VERIFY → WRITE
